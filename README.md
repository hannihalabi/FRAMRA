# Företagshemsida

En färgstark, mobilanpassad Next.js-startsida byggd som en tydlig grund för ett företags verifierade innehåll.

## Kom igång

```bash
npm install
npm run dev
```

Öppna sedan [http://localhost:3000](http://localhost:3000).

## Byt platshållare

All företagsspecifik text finns i `lib/site-content.ts`. Sök efter hakparenteser (`[ ... ]`) och ersätt innehållet med verifierade uppgifter. Sidtitel och metabeskrivning finns i `app/layout.tsx`.

Inga kundomdömen, priser, adresser, meriter eller externa bilder har lagts till eftersom sådant underlag saknas.

## Kontroller

```bash
npm run lint
npm run typecheck
npm run build
```
